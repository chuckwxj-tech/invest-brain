## 原文

The next AI bottleneck may not be GPUs. It may be memory.

But this is not a lazy “AI needs more chips, buy everything” story. Memory is cyclical, and these stocks often look cheapest exactly when earnings are peaking. The real question is not whether AI needs more memory. It does. The real question is which layer of the stack captures the economics, and how much is already priced in.

AI agents are different from chatbots. A chatbot can answer and forget. An agent browses, uses tools, reads files, writes code, checks results and stores context across many steps. That creates a physical bottleneck: memory capacity, bandwidth and storage.

At the top is HBM: fast, scarce, expensive memory sitting close to the AI accelerator. The key players are SK Hynix, Samsung and $MU. This is the cleanest AI-memory bottleneck. $MU is probably the most direct U.S.-listed play because it has HBM, DRAM and NAND exposure. It screens around ~20x trailing earnings, but much cheaper on forward/run-rate numbers. That looks attractive only if current margins are structural, not just peak-cycle shortage margins.

Below HBM is DRAM, the working memory layer for servers, PCs, phones and data centers. Samsung, SK Hynix and $MU dominate, with Nanya and CXMT trying to gain relevance. DRAM matters because HBM does not exist in isolation. It competes for wafers, tools, engineering resources and fab capacity. If AI demand pulls hard enough, it tightens the whole memory chain.

Then comes NAND, the storage layer. Agents generate logs, files, databases, checkpoints, vector stores and persistent memory. That brings in $SNDK, Kioxia, Samsung, SK Hynix/Solidigm and $MU. $SNDK is the explosive version of the thesis: it can look expensive on trailing earnings but close to ~10x forward numbers. That is also the risk. If NAND pricing stays tight, it can work. If pricing normalizes hard, the “cheap” earnings disappear quickly.

Below that is cold storage: $STX and $WDC. Not sexy, but if AI creates oceans of data, not every byte will sit on premium flash. Some of it will need cheap storage.

Then come the picks and shovels: $ASML, $LRCX, $AMAT, $KLAC and Tokyo Electron. If memory producers expand capacity, these companies sell the machines. $LRCX is more memory-capex sensitive. $AMAT is broader. $ASML is probably the highest-quality infrastructure asset, but it is not the purest memory trade. The issue here is valuation: many equipment names already trade around premium forward multiples, so the market has not exactly missed the story.

The underappreciated layer is packaging and testing. HBM is stacked memory, so bonding, packaging, inspection and test capacity matter. Names here include BESI/$BESIY, $KLIC, Hanmi, $AMKR, $ASX, $ONTO, $CAMT, $AEHR and Advantest. This is where a physical bottleneck can become very real: you cannot instantly create advanced packaging capacity just because demand appears in a spreadsheet.

Then comes memory movement: controllers, interfaces and IP. Think $RMBS, $MRVL, $AMD, $SIMO and Phison. This layer may have better economics than commodity memory because some companies sell IP, controllers or architecture instead of taking full fab-cycle risk.

The next layer to watch is CXL. HBM is fast but limited and expensive. If agents need larger memory pools outside the GPU, CXL could become a key middle layer between HBM/DRAM and storage. Relevant names include $PENG, $MU, $RMBS, $MRVL and $AMD.

ETFs are not interchangeable. $DRAM is closer to the memory oligopoly. $DISK leans more NAND/storage. $EWY gives Samsung + SK Hynix exposure. $SMH is broad semis, not pure memory.

My simplified view: $MU is the cleanest direct play. $SNDK has more upside but more cyclicality. $EWY is the best indirect Korean memory exposure. $AMAT and $LRCX are quality picks and shovels, but not cheap. $ASML is best quality, less direct.
