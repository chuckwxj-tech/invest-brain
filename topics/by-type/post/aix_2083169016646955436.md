$INTC Intel & $AMD Platforms Gain Major Boost from Montage’s Industry-First CXL 3.2 Memory Expander

Montage Technology has begun trial production of the world’s first CXL 3.2 Memory eXpander Controller (MXC). 

This is a real step forward for the entire high-performance computing and AI server stack.

CXL is the open interconnect standard that lets CPUs talk to extra memory, accelerators, and other devices with cache coherence and much higher bandwidth than traditional methods. CXL 3.2 rides on PCIe 6.x, delivering up to 64 GT/s. 

The new MXC chip is a Type-3 device that sits between the host processor and banks of ordinary DDR5 DRAM. It converts CXL traffic into native DDR commands in real time using dual controllers that run at up to 8,000 MT/s. 

Servers can add large amounts of extra memory capacity far beyond the normal DIMM-slot and channel limits of the CPU.

The chip supports PCIe AIC cards and EDSFF modules, comes with a full SDK and test tools, and has already been designed into next-generation CXL memory modules from Samsung and SK Hynix. Critically, it is built for full compatibility with current and upcoming Intel Xeon and AMD EPYC platforms.

AI workloads (especially large language models) are increasingly memory-bound. HBM on GPUs is fast but expensive and capacity-limited. Traditional server DRAM is constrained by the number of channels a CPU can drive. CXL memory expansion and pooling let data centers attach much larger pools of cheaper DDR5 that can be shared across multiple hosts. 

This raises utilization, cuts stranded memory, and lowers total cost of ownership. With Intel and AMD both shipping CXL-capable Xeon and EPYC generations, this controller removes a key bottleneck in the ecosystem.

Montage was already the first company to deliver a commercial MXC for earlier CXL versions. Being first again with a production-ready CXL 3.2 part, backed by the biggest memory vendors and both major CPU companies, puts them in a strong position as CXL moves from early adoption into real volume in 2026–2027.
