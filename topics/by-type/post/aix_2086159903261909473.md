## 原文

Seeing a lot of people say $NVDA is pivoting to Optics will crush Memory

The lazy take is HBM is getting expensive, so NVIDIA is moving to optics to replace it

I don’t think that’s what the architecture says

1. HBM and optics are different layers

HBM is GPU-local memory

Optics/CPO is data movement across switches, racks, and AI factories

(translation: fiber is not replacing the memory sitting next to the accelerator) which we have talked ALOT about... I've said this is the real bottleneck/main focus coming

2. Rubin still leans into HBM4

NVIDIA is adding optics around the AI factory, but the next platform still uses HBM4

Micron is already in high-volume production of HBM4 designed for Vera Rubin

That is not what you’d see if NVIDIA was walking away from HBM

3. The better read-through is bottleneck rotation

Memory was the obvious bottleneck

Now the market is starting to price the next one: data movement
-speed is going to be key especially for scale

Best optics/CPO based on my analytics currently:

$AVGO / $MRVL / $LITE / $COHR / $FN / $CRDO

But I would not call this bearish for $MU or $SKHY yet

The real HBM bear case is later: Dynamo/KV-cache offload, CXL pooling, HBF, and model efficiency reducing HBM per token

That is a 2027-2029 watch item, not a 2026 thesis killer

TLDR:

Optics is not killing HBM

It is proof AI clusters are getting so large that memory bandwidth is no longer the only bottleneck

NFA, I may trade around these names
