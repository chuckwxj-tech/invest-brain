## 原文

@jukan05 Moving the KV cache off the GPU doesn’t remove the bottleneck.

It relocates it.

If HBM can move data at multi-TB/s while GPU-to-CPU links are still measured in tens or low hundreds of GB/s, then memory offload creates a new constraint:

data movement.

That is why CXL matters.

Not because it “replaces” HBM, but because AI systems are increasingly becoming limited by how fast memory can move across the system — not just by how much memory exists.

The bottleneck is migrating again:

capacity → bandwidth → interconnect.

That is where I’d watch the next layer of value capture.
