【今週のHBMまとめ（7/19〜7/25）】

HBM市場は供給不足が続く一方、競争軸が製品性能から顧客・資本・人材・エコシステムへ拡大。

・Samsung：82職種で経験者採用、AMD向けHBM4共同設計で巻き返し
・SK hynix：NVIDIAとの連携を強化し、首位維持へ
・Micron：米国・日本の投資を背景に供給力を拡大
・CXMT：HBMでは遅れる一方、汎用DRAM不足で価格決定力を獲得
・Samsung、SK hynix：CXL 3.2量産でHBMを補完
・HBM増産：DDR5やNAND不足を招き、PC・スマホ・ゲーム機の値上げへ波及
・装置市場：TSV、Bonding、薄化、検査など先端Packaging投資が拡大

特に注目は、SamsungとAMDのHBM4共同設計。

今後は、

NVIDIA＋SK hynix
AMD／Google＋Samsung
米国顧客＋Micron
（＋中国顧客＋CXMT）

のような顧客別エコシステム競争が進みそう。
一方、2028年以降は3社の増産が重なり、供給過剰リスクも意識され始めた。

HBMはもはや単なるメモリではなく、

GPU
→ 共同設計
→ 長期契約
→ 先端Packaging
→ CXL・SSD

を結ぶAIインフラの中核プラットフォームになっている。
