## 原文

鋭意分析強化中。
例えば昨日は、メモリ・ストレージだけじゃなく、これまであまり注目されてこなかった周辺銘柄まで強かった。

共通項は、「データをどう持ち、どう動かし、どう安く使うか」。

私が監視しているものでも、

$STX $WDC $SNDK
$P $NTAP
$SIMO $MXL
$ALAB $MRVL $PENG

あたりがある。強化後 $QMCO $NLST が出てきた。

ざっくり分類すると、

・Memory / HBM・DRAM： $MU
・Flash / SSD： $SNDK
・Capacity Storage / HDD： $STX $WDC
・Enterprise / Cloud Storage： $P $NTAP
・Tiered / Archive Storage： $QMCO
・Storage Controller / Accelerator： $SIMO $MXL
・Memory Fabric / CXL： $ALAB $MRVL $PENG
・Memory / Storage境界領域： $NLST

少し前はCXL関連が強く、最近はストレージ本体、その周辺まで物色が広がってきた印象。

単なる「メモリ・ストレージ」ではなく、AI Data Infrastructure全体への資金拡散なのかもしれない。

今後も資金流入が続くか監視したいし、チャートが整った銘柄はトレード候補として検討してもよさそうかなと。
