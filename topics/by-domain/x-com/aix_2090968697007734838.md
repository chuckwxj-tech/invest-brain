## 原文

「推論データの置き場所」特集④

CXL本命は、$ALABか$MRVLか？

現時点の結論は、

$ALAB
→ CXL普及時の業績レバレッジ
$MRVL
→ CXL Fabric全体を取りにいく総合力

同じCXL関連でも、狙っている市場が少し違う。
【$ALAB｜Leo】

Leo CXL Smart Memory Controllerは、

・Memory Expansion
・Memory Pooling
・Memory Sharing

に対応。

CXL 2.0で、1コントローラー当たり最大2TBのメモリを接続できる。
Microsoft Azure M-Seriesでは、CXL接続メモリを顧客が評価できるPrivate Previewに採用。
AMD Instinctとの構成でも、Smart Memory Tieringが実証されている。

ALABの強みは、

① 公開済みのクラウド導入例がある
② COSMOSで管理・診断まで提供できる
③ 会社規模が小さく、Leoの本格成長が業績に効きやすい

こと。

ただし、現在の成長を牽引しているのは主にAriesとScorpio。

Leo単独の売上は開示されていない。

つまりALABは、
「すでにCXLで大きく稼いでいる銘柄」
ではなく、

CXLが本格普及した場合のレバレッジが大きい銘柄

と見る方が正確。

【$MRVL｜Structera】

MRVLはCXLの守備範囲が広い。

Structera X
→ Memory Expansion

Structera A
→ Near-Memory Acceleration

Structera S
→ CXL Switch / Memory Pooling

つまり、

メモリを増やす
→ 束ねて共有する
→ データの近くで演算する

までを一社で狙っている。

さらに、Structera X／Aはインライン圧縮を搭載。
同じDRAM容量でも、実質的に利用できるメモリ容量を増やすことで、CXL Memoryの経済性まで改善しようとしている。

CXL 2.0 Switchはすでに量産中。
次世代のCXL 3.x Switchは、2026年Q3から顧客サンプルを開始する計画。

MRVLの強みは、
① Expansion／Pooling／Near-Memory Computeを網羅
② Switchを含むCXL Fabric全体を提供できる
③ CPU・DRAM・クラウド顧客との広いエコシステム

こと。

一方でMRVLは、Custom ASIC、光通信、Ethernet、Storage Controllerなど事業が大きい。
CXLが成功しても、
会社全体の業績では効果が見えにくい

可能性がある。

現時点の比較をまとめると、

公開済みクラウド導入
→ $ALAB

製品ポートフォリオの広さ
→ $MRVL

CXL普及時の業績レバレッジ
→ $ALAB

ラック規模Memory Poolingの将来性
→ $MRVL

私の仮説は、
初期のMemory Expansion
→ $ALABが取りやすい
その先のMemory Pooling／CXL Fabric
→ $MRVLが強い

つまり、

$ALAB vs $MRVLではなく、普及段階によって主役が変わる可能性がある。

ただし、両社ともまだCXL売上の詳細は見えない。

重要なのは製品発表ではなく、

・本番採用数
・搭載台数
・量産開始時期
・CXL売上
・粗利への貢献

ここが決算で確認できるか。

次回は、
「CXLはいつ本格普及するのか？」

2026〜2028年の普及ロードマップを整理します🔍
