Where AI silicon is heading — $NVDA  Feynman, 2028:

· $TSMC A16, straight up. Nvidia is the node's first and so far only customer.
· SoIC 3D stacking, scaled up from Rubin
· Custom HBM
· CPO — optics moved inside the package

Packaging is the new node.

Rubin was chiplets + HBM. Feynman is 3D chiplet + SoIC + light. Copper has run out of reach, so the optics move onto the package.

The catch is capacity. A16 runs ~20k wafers/month at end-2027, doubling to 40k in 2028 — still short, so only the critical die gets A16 and the rest drops to N3P.

Watch the packaging fabs, that's where it shows first. TSMC's Chiayi AP7 spans 8 phases: P1 and P2 installing tools, P3 and P4 permitted. P1 was slated for $AAPL WMCM. P2 now leans SoIC, with CPO lines possibly carved out.

Advanced packaging capacity is rotating from consumer to AI, phase by phase.
