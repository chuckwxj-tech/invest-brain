## 原文

A key point that hasn’t yet been called out is that at the center of these developments is NVIDIA

HBM density as a technology is being evaluated relative to possible alternatives like memory pooling (CXL), and other parallel memory disaggregation technologies

I’m hearing we may see even further move away from high stacked HBM. SK appears to be very involved in the roadmap here, I wouldn’t be surprised if all three major memory vendors are collaborating with NVIDIA on this

NVIDIA is not only leading these discussions related to memory disaggregation, they are the only major merchant silicon provider who are in active discussions about it with suppliers

This of course has huge implications for the competitiveness of their products if they are able to manage memory more effectively across a more sophisticated memory architecture relative to their peers
