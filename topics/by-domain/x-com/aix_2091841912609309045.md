# When servers upgrade to DDR5, millions of perfectly good DDR4 DIMMs get retired. The chips are rated for 10-12 years but only see 4-5. Meta's Vistara white paper: slap a CXL con...

## 原文

When servers upgrade to DDR5, millions of perfectly good DDR4 DIMMs get retired. The chips are rated for 10-12 years but only see 4-5. Meta's Vistara white paper: slap a CXL controller (Marvell Structera) between retired DDR4 and a PCIe 5.0 bus, mount them onto brand-new DDR5 servers, and pool it all into a unified memory space.

Software side does tiered memory management. Hot data stays on native DDR5. Warm data — KV-Cache, vector indexes, that stuff — gets auto-scheduled to the CXL-attached DDR4 pool. 2-2.5x more memory per node. 25% fewer servers needed. DDR4 lifespan stretched from 4 years to 12, basically its physical limit.

The obvious objection: DDR4 has worse bandwidth, won't it hurt AI? For LLM inference, vector DBs, KV-Cache — the bottleneck is capacity, not transfer rate. You're stalling because you ran out of space, not because the pipe is too slow. PCIe 5.0 bandwidth + software scheduling absorbs the latency difference. Inference throughput barely budges.

DDR5 supply is getting squeezed by HBM. Prices only going one direction. Repurposing retired DDR4 as a secondary memory pool costs way less than buying more DDR5. The real takeaway: inference bottlenecks in data centers are about capacity, not speed. Meta's just the first to say it out loud. https://t.co/5xhBLelmb0
