## 原文

@GavinSBaker agree, 3D DRAM/HBM is likely going to be standard solution in the coming years, from cloud to edge. Qcom/NV already started year ago

at the end of day it's all about chasing lower pJ/byte + higher BW, 3D DRAM has the advantage:
wide IO bus width + lower freq + closer to logic(low IO) = lower pJ/byte

my bet is 3D DRAM is easiser/earlier than zHBM, because heat and HBM base die challenges are harder. 3D DRAM's issue is power delivery through TSV, which mainly limit the max freq of logic die

DRAM on logic is more likely to happen on edge devices

memory hierachy innovation is going to be revive again these years to break memory wall😂:

3D DRAM is like G0.5 level
CPO HBM is like G1.2 level
HBF like G1.5
CXL(around CPU) like G2.5
ICMS/CMX is like G3.5

which means co-design/co-package is more likely to happen between memory vendor and fabless
