## 原文

Back in July, I argued that the memory wall was forcing the industry down three architectural paths:

Distance → $QCOM HBC
Compression → $NVDA Rubin 3.125-bit LUT
Pooling → CXL / disaggregated memory

Now $MRVL is pushing #3 one step further:

Structera pushes memory pooling across the rack with CXL. Photonic Fabric pushes it across racks with optics.

The memory wall is increasingly becoming a data-movement problem, not simply an HBM problem.
