Memory Update｜产业向上，价格向下？

继续更新 Memory。

2028 HBM 需求预测里，Broadcom 35–40bn Gb、NVIDIA 30bn Gb、Google 20bn Gb、AMD 10bn Gb。真正重要的不是谁超过谁，而是 HBM 正从 GPU 单引擎 → GPU + Custom ASIC 多引擎。

但价格周期正在给另一种信号。美股风险资产重新转弱，今天韩国存储也低开。我们仍保留原来的判断：Memory 产业周期向上，但8–9月价格周期可能还有更好的低点。 所以前期反弹继续减仓，现在不急着接。

下一阶段，我们反而开始寻找下一棒：HBM → DRAM / CXL → NAND / SSD，对应 AI Memory 从 Bandwidth → Capacity → Persistence 的扩散。

产业决定看哪里，周期决定等多久，价格决定什么时候回来。
