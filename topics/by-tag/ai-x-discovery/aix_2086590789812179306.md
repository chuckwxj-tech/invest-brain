## 原文

【「AIの次は光」ブームが来るのか？】

最近「AIの次は光」と言われています。

ただ、今話題になっている「光」の中心は、まだGPUのすぐ隣ではありません。

主戦場は『Scale-out側のネットワーク』です。

現在のAIクラスタでは、

GPU/XPU近傍・ラック内 → 電気接続が中心
ラック間・Scale-out → 光が大量に使われる

という構造になっています。

そして最近、「光」が一段と話題になっている理由は、
このScale-outの領域そのものが猛烈に拡大しているから。

NVIDIAは2026年3月にLumentum、Coherentへそれぞれ20億ドルを投資。

さらにCorningとも提携し、光ファイバー・光接続の供給能力を大幅に拡大しようとしています。

そして特に面白いのが、CPO（Co-Packaged Optics）です。

従来は、

Switch ASIC
↓ 電気信号
フロントパネルの光トランシーバー
↓
光ファイバー

だったものを、

光エンジンをSwitch ASICのすぐ近くまで持ってくる。

つまり、

「光が外側からGPU方向へ近づいている」

わけです。

ただし、ここが重要。

CPOで光が近づいている先は、現時点では主に『GPUではなくSwitch ASIC』です。

私はAIインフラをこんなイメージで見ています。

AIのボトルネックはGPUから外へ →

GPU
→ HBM
→ PCIe / CXL
→ Scale-up
→ Multi-rack
→ Scale-out

一方、

光は遠いところからGPUへ ←

XPU近傍 / Optical I/O
← Multi-rack Scale-up
← Switch CPO（＊今ここが急速に進展）
← Rack間 / Scale-out
← DCI

つまり、

AIのボトルネックはGPUから外へ。
光は遠いところからGPUへ。

両者は『逆方向から近づいてくる』イメージです。

そして投資目線で面白いのは、この先。

現在：Scale-outで光需要が急拡大
↓
2026年後半〜：CPOでSwitch ASICまで光が接近
↓
次：Multi-rack Scale-upへ
↓
さらに先：XPU近傍 / Optical I/Oへ

ここまで来たら、本当の意味で

「光がGPUまでやってきた」

と言える。

だから私は、今の光ブームを

「遠いところにいた光が、GPUへ向かって近づいている途中」

と捉えています。

そしてこの先、Multi-rack Scale-up、さらにGPU/XPU近傍まで光が入り込んできた時、『本当の意味で「光の爆発」が来る』と思っています👀

このイメージ、伝わりますか？
