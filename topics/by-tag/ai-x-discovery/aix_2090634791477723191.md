## 原文

This paper connects two technology roadmaps.

The first is memory disaggregation:

Local Memory → CXL Expansion → CXL Pooling → Memory becomes a pooled resource

The question it tries to solve is simple: Why does memory capacity have to remain statically tied to a specific CPU or GPU?

The second is Optical I/O:

Pluggable Optics → CPO → Optical Chip-to-Chip → Optical Memory Interface

This roadmap addresses a different problem: As memory becomes increasingly disaggregated and physically farther away from compute, how can data still be moved at extremely high bandwidth and low power?

Eventually, these two roadmaps converge into an Optical Memory Fabric:

XPU ↔ Optical ↔ Memory Pool

In other words, optical interconnects could eventually extend all the way to the XPU-to-memory interface.

This does not mean HBM becomes less important. A more plausible architecture is Local HBM + Optical Pooled Memory.

Local HBM would remain the memory tier closest to the XPU, offering the highest bandwidth and lowest latency, but at high cost and with limited capacity. Optical pooled memory would sit farther away and be somewhat slower, but could provide much larger capacity.

This is still far from commercialization, but it points to another potential expansion of the optical TAM: from scale-out, to more scale-up links, and eventually perhaps even XPU-to-memory connectivity.
