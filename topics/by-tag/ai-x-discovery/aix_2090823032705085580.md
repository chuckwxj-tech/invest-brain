The core thesis holds — and it’s confirmed independently of this post.

NVIDIA hasn’t officially confirmed Rubin Ultra’s final spec, but TrendForce (Aug 4 report) and SemiAnalysis already covered the shift from HBM4E 12-Hi (288GB) to HBM4 8-Hi (192GB). 

Same driver: an HBM/DRAM shortage expected to run through 2027.

This isn’t a hypothesis anymore, it’s live deals:

  Marvell ($MRVL) + NVIDIA — $2B investment, joint work on silicon photonics and scale-up networking (NVLink Fusion, March 2026)
  Marvell + SK hynix — CMM-Ax, CXL-based memory disaggregation, shown at FMS 2026
  NVIDIA also invested in Lumentum ($LITE) — same photonics logic

When per-GPU memory hits a physical ceiling, the value doesn’t vanish. It MOVES to connectivity.

That’s the structural case for optics — not a narrative, but where the capital is actually going right now.
