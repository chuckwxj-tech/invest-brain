## 原文

「推論データの置き場所」特集⑤

CXLは、いつ本格普及するのか？

現時点の私の仮説は、

2026年：初期導入
2027年：量産採用の選別
2028年以降：Memory Pooling本格化の候補

ただし、2028年に突然すべてがCXLへ切り替わるわけではない。

CXLは、

① Memory Expansion
② KV Cache Offload
③ Memory Pooling / Sharing
④ Rack-scale CXL Fabric

の順番で、段階的に普及すると見ている。

【2026年｜PoCから初期導入へ】

すでに、

・Azure M-Seriesで$ALAB Leoを使ったCXL Memoryを評価
・$PENGがCXLベースのKV Cache Serverを製品化
・$PENGは金融機関への導入も公表
・$MRVLのCXL 2.0 Switchは量産中
・次世代CXL 3.x Switchも顧客サンプル開始へ

というところまで来ている。

つまりCXLは、もう単なる研究テーマではない。

一方で、

「製品が存在する」
と
「業績を動かすほど量産される」

の間には、まだ距離がある。

例えば$ALABはLeo単独の売上を開示していない。

2026年は、

CXLが使えるかを検証する年から、最初の本番採用が始まる年

という位置づけだと思う。

【2027年｜量産採用の選別】

ここで確認したいのは、

・Private Previewから正式サービスへ移行するか
・1社の採用が複数社へ広がるか
・追加受注やリピート受注が出るか
・CXL関連売上が決算で見えるか
・DB／HPCではなくAI推論で採用が増えるか

おそらく最初に普及するのは、

1台のサーバーにメモリを追加するMemory Expansion

だと思う。

構成が比較的シンプルだから。

一方で、複数のCPUやGPUからメモリを共有するMemory Poolingには、

・CXL Switch
・CPU／GPU側の対応
・OS
・Memory Tiering Software
・管理／オーケストレーション

まで必要になる。

そのため、

Memory ExpansionとMemory Poolingを同じ時間軸で考えない方がいい。

【2028年以降｜ラック共有資源へ】

CXL 3.x対応Switch、サーバープラットフォーム、ソフトウェアが揃えば、

メモリは、

「各サーバーに固定された部品」

から、

「ラック全体で必要な場所に割り当てる共有資源」

へ変わる可能性がある。

ここまで進めば、

DRAM容量
→ $MU

CXL Controller
→ $ALAB $MRVL

CXL Switch
→ $MRVL

KV Cache System
→ $PENG

という複数のレイヤーに、同時に需要が発生する。

ただし、CXLが必ず主役になるとは限らない。

競合するのは、

・大容量HBM
・SOCAMM
・高容量RDIMM
・CPU接続LPDDR
・NVMe SSDへのKV Cache Offload

など。

CXLは技術的に優れているだけでは不十分。

既存の選択肢より、推論性能とTCOをどれだけ改善できるか

が勝負になる。

私の中心シナリオは、

2026年
→ 評価から初期導入へ

2027年
→ 採用企業と売上が増えるかを検証

2028年以降
→ Memory Pooling / CXL Fabric本格化の可能性

つまりCXLは、

「まだ来ていない」のではなく、
「すでに始まったが、広範な量産普及はこれから」

という段階だと思う。

投資で見るべきなのは、最新規格の数字ではない。

Design Winが、いつ売上に変わるのか。

次回は、

「CXLの最大のライバルはSOCAMM？」

CXLが普及しないシナリオも掘ります🔍
