## 原文

SK Hynix restated the core AI constraint in plain terms.

At the Dell Technologies Forum, system architecture VP Joo Young-pyo argued that overall AI system performance is now set by memory bandwidth more than by raw GPU compute. 

Large language models already move enormous volumes of data; agentic workloads and longer context push the requirement from tens of tokens per second toward hundreds or thousands.

HBM has scaled rapidly from the first generation through HBM4, yet the company says it is no longer sufficient on its own for the next wave of agentic systems. 

Stacking memory directly on the GPU could deliver far higher bandwidth, but thermal limits make that path difficult. Energy is another pressure point: most power is spent moving data rather than computing, which is why processing-in-memory research continues.

Memory pooling over CXL is being used to cut the time GPUs sit idle waiting for data and to improve overall cost efficiency. 

Efficiency gains elsewhere, including algorithmic improvements, have so far followed Jevons’ paradox and increased rather than reduced total memory demand.

The message is consistent with what the industry is seeing in the field. Compute keeps advancing, but the system is increasingly gated by how fast and how efficiently data can be supplied.
