## 原文

Traditional server architectures fix memory capacity at deployment time. As AI models grow larger and workloads become more memory-intensive, that rigidity creates stranded resources, inefficient utilization, and a well-documented memory wall bottleneck.

The Marvell Structera S CXL switch addresses this by enabling memory pooling and composable infrastructure across servers. The industry's first CXL 2.0 switch, the Structera S 20256 delivers 256 lanes, up to 2 TB/s switching capacity, and ultra-low latency data paths optimized for CXL memory traffic, decoupling memory from compute so resources can be dynamically allocated where workloads require them.
