Top 10 takeaways from Hot Chips 2026 so far 

(**Dynamic, conference runs through Tuesday)

1. $NVDA — inference gets another growth engine
Groq 3 LPX is now in production alongside Vera Rubin, targeting ultra-fast token generation. NVIDIA is expanding from GPUs into specialized inference + networking + DPUs as one integrated AI platform.
2. $AVGO — 3D custom silicon thesis keeps getting validated
Hot Chips is increasingly about memory, chiplets, data movement and 3D integration. That maps directly to AVGO’s 3.5D XDSiP custom XPU platform plus Ethernet. AVGO can help build the XPU, package it and connect it.

3. $ARM — major business-model expansion
Arm detailed AGI, its first complete commercial server CPU: up to 136 cores, >800GB/s memory bandwidth and a chiplet architecture. ARM is moving beyond IP royalties toward capturing actual silicon revenue.
4. $MU — the memory wall is getting worse
Micron showed accelerator compute growing ~3x every two years while HBM bandwidth grows <2x. More AI compute increasingly requires more expensive, higher-bandwidth memory. Very bullish for HBM content.

5. $INTC — credible inference comeback attempt
Diamond Rapids reaches 256 cores and uses 18A + Foveros Direct 3D. Crescent Island pairs 480GB LPDDR5X with a 350W air-cooled GPU aimed at lower-cost agentic inference.
6. $TSM — complexity keeps increasing
Arm AGI uses TSMC N3P, d-Matrix uses N4, and next-gen XPUs increasingly rely on advanced packaging. More chiplets and 3D integration means more value moving toward leading-edge foundry + packaging.

7. $AMAT — 3D stacking becomes a capex cycle
HBM, hybrid bonding, TSVs, wafer thinning and logic-on-memory architectures require more deposition, CMP and packaging steps. More complexity = more equipment intensity.
8. $KLAC — yield becomes more valuable
Stack more dies, HBM and chiplets together and one defect becomes much more expensive. Advanced packaging increases inspection and metrology requirements.

9. $ANET — networking becomes part of the compute system
NVIDIA is talking about Ethernet fabrics scaling toward 512K GPUs. That validates the size of the AI networking opportunity, although Spectrum-X is also direct competition.
10. $MRVL — heterogeneous AI favors connectivity
Custom XPUs, CXL memory, optical links and huge inference KV caches all increase the importance of moving data efficiently. That plays directly into Marvell’s custom silicon + interconnect strategy.

Big picture: Hot Chips is showing AI capex broadening beyond GPUs.
The scarce resources are increasingly memory bandwidth, advanced packaging, interconnect, power efficiency and data movement.
