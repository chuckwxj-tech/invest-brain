AI产业链核心标的一周总结（8.10-8.16）
1️⃣ 最高优先级 — MU（美光）：存储单边逻辑被财报二次兑现 上周「最强单边」判断本周获硬验证：FQ3'26 营收 41.46B（+346%）、GM 84.9%、HBM 2026 售罄、Q4 指引 50B（超预期）、16 份 SCA（100B RLO）、JPMorgan 给出 2027 HBM ASP 2.8/Gb（+42%）。叠加 DRAM 合约价 Q3 指引 +1521%，MU 仍是风险收益结构最优的存储 Beta（有 cap、底价毛利超历史峰值）。
2️⃣ 高优先级 — NVDA：叙事裂缝未修复，但短期尾部风险缓和 坏消息面延续：算力租金源冻结走平、Kalshi 押注 B200 不破峰值、250 EOM 概率从 ~50% 跌至 9%（上行逼空预期消失）。H100 现货地板回升至 2.19，泡沫触发线距离拉远；DC 营收 75B/+92% 与 8/26 财报共识 91.8B/$2.08 仍强。
3️⃣ 高优先级 — COHR / ALAB：最干净 Beta 维持 光互联（COHR）+ PCIe/CXL 互联（ALAB）仍同时受益于 Capex 上行 + Blackwell 集群规模化，且不承担 HBM 成本冲击、不受 GPU 租金波动实质影响。本周无任何数据点对其构成负面，逻辑最顺。与上周一致，视为「卖铲子里的连接器」组合。
4️⃣ 高优先级 — SK海力士：与 MU 同级、更纯的存储 Beta 份额 >57%、长协锁至 2028、唯一无价格上限、HBM4 2027 翻倍指引、DDR4 退出转产 HBM 的供给收缩——所有存储侧数据点对其均正面。相对 MU 无 cap 约束、上行弹性更大。
5️⃣ 需重新审视 — GOOGL：双面性加剧 token 成本通缩 + GCP 大单 + 算力租金走平利好其经济性；但作为 Capex 支出方，$710B 行业总盘 + DRAM/HBM 翻倍实打实压制 FCF。
6️⃣结构性问题 — AMD / MRVL 的「验证真空」延续 MI355X 在 Kalshi 仍无主要挂牌；Google-SpaceX 11万 GPU 大单上周已削弱 MRVL 的 ASIC 替代叙事，本周 Anthropic IPO 强热门、模型能力向 Claude 集中，进一步挤压「非 NVDA AI 链」的叙事空间。
