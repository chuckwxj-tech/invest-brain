A few more thoughts on FMS 2026 (2).

How to deal with shortages of HBM and local DRAM was one of the main themes across this year’s exhibitors.

Beyond accelerating the use of NAND for KV cache offload, CXL-based KV cache offload was another topic gaining visibility.

The two address the shortage differently. At its core, NAND adds memory capacity, although its access speed is much slower than DRAM. CXL is more about improving the utilization of existing HBM and DRAM.

CXL connects different nodes and allows memory that would otherwise remain isolated behind each node to form a shared pool. Memory from that pool can then be allocated across nodes according to workload demand.

Combined with an efficient memory allocation algorithm, this allows a system to make better use of idle HBM and DRAM capacity across its nodes, improving overall utilization.

The basic idea behind CXL memory pooling already exists in NVIDIA $NVDA systems.

NVL72 uses NVLink and NVLink C2C to connect GPUs and CPUs across different trays. GPUs can access memory beyond their own package, including peer GPU HBM and Grace CPU memory within the same rack. This already improves memory utilization at the rack level.

So personally, I think the interconnect technologies behind CXL and NVLink are more interesting than CXL itself.

In its “Scale Up and Scale Out Fabrics for AI” presentation at FMS, Marvell $MRVL showed how Photonic Fabric could extend CXL from within a server or rack to a cross-rack architecture, improving DRAM utilization across multiple racks.

NVIDIA is moving in the same direction with Rubin Ultra NVL576. It will use direct optical connections for cross-rack scale-up, combining eight racks into a single 576-GPU NVLink domain. Through NVLink and NVSwitch, memory across different racks can become accessible within the same system fabric, improving the utilization of HBM and DRAM across the entire system.

This context also helps explain why SK hynix $SKHY, a memory company, suddenly released a CPO technology roadmap this week showing optical interconnects between an XPU pool and a memory pool.

Put simply, a shortage of DRAM does more than increase demand for NAND as an additional capacity tier. It also increases demand for high-speed data interconnects between nodes.

Both NAND and optical interconnects should benefit from the shortage of DRAM.

...but none of this is exactly new. Consider it FMS 2026 giving everyone a quick recap.
