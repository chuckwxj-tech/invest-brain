## 原文

A slower GPU can beat the fastest GPU when it has better memory and storage.

SemiAnalysis tested NVIDIA, AMD, Google and Amazon chips using more than $5M of real Claude Code traces.

Agentic AI creates enormous KV caches. This is the model’s working memory.

When GPU memory fills, the chip must wait for data, move it from storage or calculate it again. Raw GPU speed matters less when the GPU spends its time waiting.

That is why an $AMD GPU with more memory can beat an $NVDA GPU on some inference workloads.

The investment read-through

• $SNDK: high-speed enterprise SSDs and high-bandwidth flash
• $SKHY: HBM plus Solidigm storage
• $005930: HBM, DRAM, NAND and CXL memory
• $MRVL and $ALAB: storage, PCIe and CXL connectivity

Leather Jacket Man (LJM) remains the full-stack leader because he also controls networking, CPUs, software and rack architecture.

Measuring AI systems by GPU speed alone is becoming less useful (and perhaps not useful at all)
