Research|Takeaways from the Future of Memory and Storage Conference 2026

Memory stays tighter for longer: We do not read the recent flattening in memory ASP growth as a sign of coming oversupply. Higher CSP LTA mix, consumer price sensitivity, and data-center demand should keep memory prices elevated through 2027.

Demand still exceeds supply: Smartphone and PC channels remain memory-constrained, while CSPs are pursuing a “buy all available capacity” strategy. Kioxia said it can fulfill only 40%–50% of demand, likely referring to US data-center SSD demand.

AI servers raise the bar: We project 2027 x86 server CPU shipments to grow >40% YoY and XPU shipments >60% YoY, both requiring large volumes of high-spec memory. Nvidia and others are downgrading some specifications to maximize GPU shipments under limited memory supply.

CXL and HBF gain visibility: CXL memory expansion is expected to ramp in 2027, with pooling adoption starting in H2 2027; Marvell’s Structera S CXL 3.x switch begins sampling in 26Q3. HBF is also drawing attention, with 2027 targeted for samples and 1.5–2TB possible on one package using three to four HBF stacks.
