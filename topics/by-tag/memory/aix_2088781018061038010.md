【今週のAIインフラ主要ポストまとめ｜8/9〜8/15】

今週の投稿から、後から読み返したいAIインフラ主要ポスト12本をまとめました👀

今週特に見えてきたのは、
① 高速化・複雑化で、接続に加えて検査・検証が新たなボトルネックへ
② 光・CXL・メモリが、部品単体からラック規模のFabricへ進化
③ 成長期待だけでなく、契約構造・利益率・仮説崩壊条件まで検証

今週の主要12本👇

① FORM / VIAV / AEHR｜検査工程別の勝ち筋比較

AIインフラ向け検査・検証の3社を、FORMのWafer Test、AEHRのBurn-in、VIAVのFabric Validationに分けて比較しました。成長余地、評価水準、UALoEやNative UALinkへの展開仮説まで含め、投資妙味を工程別に捉える整理です。
https://t.co/9xZdzOTjHi

② ALAB / CRDO / VIAV｜Scale-up規格別シナリオ

Ethernet系Scale-upとUALink系のどちらが主流になるかで、ALAB、CRDO、VIAVへの追い風がどう変わるかを整理しました。勝つ規格を一点予想するのではなく、接続・伝送・検証を組み合わせて不確実性に備える視点が重要です。
https://t.co/c6Gsop61JH

③ 光｜Scale-outからGPUへ近づく成長経路

現在の光需要はScale-outが中心で、CPO、Multi-rack Scale-up、XPU近傍のOptical I/Oへ段階的に近づく構図を振り返りました。光が今どこにあり、次にどこへ広がるかを分けることで、需要拡大の時間軸を見誤りにくくなります。
https://t.co/BjpN4X7POu

④ VIAV｜FY2026 10-Kで仮説を再検証

FY2026 Form 10-Kから、旧Spirent取得3事業の売上寄与、NSEの利益率改善、Data Center Ecosystemの位置づけを確認しました。一方でHSE単独成長率やUALink対応は未確認で、次四半期の売上再加速とキャッシュ変換が重要な検証点です。
https://t.co/TyFRNTm2Ta

⑤ MRVL / ALAB｜CXL Fabricの競争軸

ALABのLeoはCXL Memory Controller、MRVLのStructera SはCXL Switchであり、現状は共存可能だと整理しました。ただしCXLがサーバー内の拡張からラック規模の共有Memory Fabricへ進めば、Fabric中央を握る競争が重要になります。
https://t.co/0XS8ZWwCy1

⑥ AEHR｜Burn-in設備需要を決める構造

AEHRの設備需要を、半導体数量、Burn-in採用率、検査時間・強度の掛け算として捉え直しました。不良率の多さではなく、高価な半導体を後工程へ流す損失と、大量並列で信頼性を確認する必要性が事業モデルの核心です。
https://t.co/spub5brG9N

⑦ CRDO｜AECから光へ広がる高速接続仮説

AECを現在の成長源としながら、SerDes、DSP、DustPhotonicsのSiPho PIC技術で1.6T、3.2TやNPO/CPOへ広がる仮説を振り返りました。顧客集中、世代移行、競争、光事業の立ち上がりを継続確認することが重要です。
https://t.co/87IdMbsHDj

⑧ Marvell｜Compute・Memory・StorageのFabric化

OCTEON DPU、Prestera Ethernet、NVMe-oFで分散型ストレージを構成したデモを整理しました。単体の技術革新というより、Compute、Memory、Storageを分離し、広い接続製品群でFabric化するMarvellの戦略を読む材料です。
https://t.co/tLm448QHyT

⑨ SNDK｜循環型NANDから長期契約モデルへ

Investor Day後の再評価を、HBF期待だけでなく、2030年までの高収益目標と長期契約NBMによる出荷カバーとして分析しました。市況変動の大きいNANDメーカーから、AI推論・KV Cache需要を長期契約で取り込む企業へ変われるかが焦点です。
https://t.co/8IbSA6IExY

⑩ INTC / ALAB｜積層メモリとCXLの役割分担

Intel周辺のZAM、XBM、UCIe、Advanced Packagingの動きを結び、積層メモリからCXL Memory、SSDまでの新しいMemory Hierarchyを考えました。積層メモリは帯域・Latency、CXLは容量・コスト・Poolingを担うという役割分担が重要です。
https://t.co/015AuDpqjh

⑪ VIAV｜AI Fabric Testへの投資仮説

通信が400Gから800G、1.6T、3.2Tへ高速化し、Test / Validationが新たなボトルネックになるとの仮説を振り返りました。AI/Data Center比率、旧Spirent HSEの成長、次世代でも二強を維持できるかが投資判断の軸です。
https://t.co/H9AsN0OZNY

⑫ ALAB｜AIラック接続基盤を学ぶ用語図鑑

Astera Labsの企業像からAries、Scorpio、Leo、Taurus、COSMOS、PCIe 6、CXL、Scale-up／Scale-outまでを全10回で整理しました。ALABをPCIe Retimer企業にとどめず、AIラック全体の接続基盤として理解するための索引です。
https://t.co/9cFSVTP92L

今週のAIインフラを一言でまとめると、
「AIの性能競争はGPU単体から、接続・光・メモリ・ストレージを束ねるFabricへ拡大。高速化を支える検査・検証と、収益の持続性を見極める視点が一段と重要になった週でした。」
