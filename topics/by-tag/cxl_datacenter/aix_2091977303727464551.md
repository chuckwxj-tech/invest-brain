## 原文

At #HotChips2026 @intel @Intel_Foundry executives shared some great perspectives and peek into the Agentic AI future powered by Intel from Cloud to Edge.

1. Diamond Rapids (next Xeon 7) — Akhilesh Kumar and Krishnakanth Sistla, CPU session

2. Wildcat Lake (Intel Core Series 3) — Lance Hacking, CPU session

3. Crescent Island (inference GPU) — Sumit Mohan and Hong Jiang, GPU session, after NVIDIA Rubin and AMD MI400

CTO Pushkar Ranade’s @magicsilicon line is the strategy in one sentence: 

“Tightly couple general-purpose compute with purpose-built acceleration, advanced packaging, and open chiplets, then scale inside real power, cost, and cooling limits”

Unpacking Diamond Rapids

1. Diamond Rapids : next Xeon, modular, 256 P-cores

- Up to 256 P-cores (Panther Cove-X), no SMT (No Hyper-Threading.SMT returns on Coral Rapids in 2028)
- 1.28 GB LLC shared across the package
- 16 memory channels, up to 12,800 MT/s MRDIMM (DDR5 up to 8,000 MT/s)
- 128 PCIe Gen6 + CXL 3.0
- Built on Intel 18A-P compute tiles
- TDP up to ~650 W on a huge LGA 9324 socket
- Target: 2027

Intel has fully gone chiplet-first (more like AMD EPYC) calling it a “Fan Out” fabric SoC

- 16 compute chiplets on 18A-P (16 cores each in the CBB description)
- Four Compute Building Blocks (CBBs)- each CBB is a modular cluster of up to 64 cores
- Two fabric hubs / I/O-memory tiles (Intel 3)
- 4x Base tiles carrying the large LLC (Intel 3-T)
- Foveros Direct 3D Hybrid Bonding inside the stack
- Die-to-Die : UCIe-S copper links on the substrate between tiles
