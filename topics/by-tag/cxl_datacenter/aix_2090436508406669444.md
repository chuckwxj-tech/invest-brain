SK Hynix wants to completely dominate the memory market:

HBM solved the memory bottleneck inside the accelerator. However, once you have thousands of GPUs, the problem now becomes interconnect. $NVDA made a play by investing heavily into photonics (CPO, co-packaged optics). $SKHY believes that the endgame is extending optical links all the way to the memory interface. A photonic interposer could directly connect processors to a shared memory pool.

This is part of $SKHY's push to cHBM (something I bring up over and over again on this account). The shift from commodity to custom transition. CPO + HBF + CXL pooling all point to cHBMs.
