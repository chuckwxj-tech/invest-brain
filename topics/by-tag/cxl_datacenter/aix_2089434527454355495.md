## 原文

In my view, this near‑memory‑processing + CXL KV‑cache offload stack from $MRVL and $SKHY is one of the most practical long‑context inference breakthroughs we have seen lately, and it signals a meaningful shift for the broader GPU market, including $NVDA.

Raw GPU VRAM will never scale fast enough to keep up with 1M+ token context workloads. Simply throwing more GPUs at the KV‑cache bottleneck is costly and quickly hits diminishing returns. The CMM‑Ax / NELSSA architecture unlocks a new scaling vector: offloading bloated KV‑cache pools into high‑capacity external memory and processing data in‑situ, rather than continuously shuffling payloads back‑and‑forth across the PCIe bus. The real‑world throughput gains on Llama3‑8B‑1048K are compelling, delivering up to 5.5× throughput versus a single‑GPU baseline and 3.6× against a dual‑GPU setup, with zero additional high‑end GPU silicon.

That said, this is not an existential threat to NVIDIA. NVIDIA’s core moat still lies in dense on‑die compute and its mature, widely‑adopted CUDA software stack, and NVIDIA itself is actively advancing its own memory‑offloading, CXL and NVLink roadmaps to tackle this exact KV‑cache pain point.

Widespread KV‑cache optimization across the industry will not replace GPU compute capacity, but it rewrites inference economics. Cloud operators will be able to run far more long‑context workloads on their existing GPU fleets, lifting utilization while potentially slowing incremental GPU purchase growth for pure long‑context chat deployments in the near‑term.
The longer‑term risk for NVIDIA arises if hyperscalers begin fully decoupling KV‑cache storage and processing from the GPU die, building disaggregated inference architectures that deliver equal overall throughput with fewer flagship GPUs.

Two critical open questions emerge: how rapidly can this near‑memory CXL ecosystem scale into production racks, and will this disaggregated‑memory trend push NVIDIA to accelerate adjustments to its on‑board‑memory product roadmap over the next 2‑3 years?
