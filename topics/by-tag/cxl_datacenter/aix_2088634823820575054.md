# ช่วงนี้ผมเริ่มสนใจ CXL มากขึ้น เพราะมัน Connect กับเรื่อง “Memory Wall” ของ AI Morgan Stanley ประเมินว่าตลาด CXL Memory Expander Controller + CXL Switch จะโตจากแทบไม่มี TAM เลยต...

## 用户备注

来源: ai-x-discovery；机器初筛，仍需外部核查。

## 原文

ช่วงนี้ผมเริ่มสนใจ CXL มากขึ้น เพราะมัน Connect กับเรื่อง “Memory Wall” ของ AI

Morgan Stanley ประเมินว่าตลาด CXL Memory Expander Controller + CXL Switch จะโตจากแทบไม่มี TAM เลยตอน 2025 ไปเป็น TAM ที่มีมากกว่า $4B ภายในปี 2030

CXL คือไร? ง่ายๆ มันคือเทคที่ทำให้ CPU/GPU สามารถ ต่อ Memory เพิ่ม + แชร์ Memory เป็น Pool ได้ แทนที่แต่ละเครื่องจะต้องแบก Memory เองทั้งหมด ซึ่งสำคัญมากกับ AI Inference ในอนาคต เพราะ Context + KV Cache มันจะกิน Memory หนักขึ้นเรื่อยๆ

และหุ้นที่ผม Connect แล้วคิดว่าน่าสนใจคือ
- $ALAB Leo CXL Memory Controller
- $MRVL Structera CXL Memory Controller + Switch
- $PENG เอา CXL ไปสร้าง KV Cache / MemoryAI สำหรับ Inference
- $MU ยิ่ง Memory Pool ใหญ่ Demand DRAM ก็ยิ่งเพิ่ม
- $MCHP มี CXL Memory Controller

Insight คือ...
-> AI รอบเวฟต่อไปอาจจะต้องมาแก้คอขวด “Memory Wall”
-> ถ้า Agentic AI + Long Context ทำให้ KV Cache ใหญ่ขึ้นเรื่อยๆ เราอาจจะแก้ด้วยการยัด HBM แพงๆ เข้า GPU อย่างเดียวไม่ได้

ตรงนี้แหละที่ CXL น่าจะกลายเป็นอีก Layer สำคัญของ AI Infra และผมว่า $ALAB, $MRVL, $PENG น่าตามมากๆ นะ ในตรีมนี้
