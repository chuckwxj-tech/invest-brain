Memory is the real AI bottleneck. Agentic workloads make HBM the scarce resource - not GPUs.

The divergence most miss is that agentic workloads turn KV-cache and persistent state into the binding constraint: long context and multi-step tool use scale memory demand super-linearly while leaving FLOPs idle when HBM (High Bandwidth Memory) is exhausted.

Compute has scaled faster than high-bandwidth capacity; the result is a structural shortage that experts now project into 2028. In a higher-for-longer rate environment this reallocates scarcity value toward memory producers and hierarchical architectures rather than pure accelerator counts. 

Historical computing cycles show the bottleneck always migrates to the scarcest input - memory is that input for AI Agents. 

Bullish for $AMKR $ASX $TSM $AVGO $MRVL $AMD $SNDK $WDC $STX $NVDA 

CXL (Compute Express Link) memory expansion enables coherent attachment of additional DRAM (or tiered memory) beyond traditional CPU/GPU socket limits. 

It supports memory pooling, sharing, and expansion over a high-speed interconnect (built on PCIe physical layers), allowing systems to scale capacity and improve utilization without adding more expensive HBM or accelerators.

This is highly relevant to the Agentic AI memory bottleneck: long-context KV-caches, multi-step state, and concurrent agents drive super-linear memory demand. CXL helps offload “warm” data from scarce HBM, improves GPU efficiency, and enables rack-scale pooling.
