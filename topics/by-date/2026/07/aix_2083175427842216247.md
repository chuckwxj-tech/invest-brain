AI Didn't Invent New Memory — It's Splitting Up the Old Kind

Summary: AI hasn't created a new memory category. It's redistributing the capacity/latency/power trade-off across HBM, LPDDR, and CXL — three existing technologies now being layered rather than replaced.

Why now
HBM capacity from SK hynix, Samsung, and Micron is effectively sold out through the end of 2026. Meanwhile, AI workload weight is shifting from training to inference, where response latency and memory footprint — not raw throughput — become the binding constraints. Growing KV-cache size from longer context windows and MoE/agentic architectures is eating into scarce HBM capacity, leaving GPUs idle for lack of memory rather than compute.

What's moving
- Rambus announced its SOCAMM2 chipset (April 2026) — the first in a planned family of LPDDR-based server module chipsets. Note: Rambus sells the control/power-management silicon, not the memory itself; Micron has already been sampling actual 192GB SOCAMM2 LPDDR5X modules to customers since October 2025.
- Micron has repeatedly flagged low-power DRAM as a major data-center growth opportunity across recent earnings calls, tied directly to the inference-driven shift in design priorities.
- CXL is emerging as a tier between local memory and SSD storage, extending system memory capacity at far higher bandwidth/latency than storage to absorb KV-cache and long-context demands.

The nuance that matters
HBM retains a meaningful power-efficiency edge over GDDR6 (commonly cited in the 40–50% range, though the gap varies by generation) plus far higher bandwidth — but it's expensive and capacity-constrained. Hyperscalers are responding by routing inference workloads, where performance-per-watt is the deciding factor, to cheaper, lower-power LPDDR and CXL tiers. This is not a sign of weakening HBM demand — it means HBM stays the top tier while a new tier is being built underneath it.

Where Korea stands
SK hynix holds a clear low-50s-percent HBM market share lead. The #2 and #3 spots (Samsung vs. Micron) are genuinely contested across data sources — some report Micron ahead of Samsung in certain quarters, others the reverse — so treat any fixed ranking claim with caution. More importantly, in the next tier down (LPDDR server modules, CXL controllers), the names surfacing first are American — Rambus and Micron. Whether Samsung and SK hynix (Korea's two memory majors) can also lead design and standards in this emerging tier remains an open question.

Unresolved risks
CXL's software stack and latency overhead are still early in real-world validation.
It's unclear whether the HBM shortage is accelerating a durable tiering trend or just a temporary distortion — easing HBM supply could change the pace.
There's no standardized framework yet for which inference workloads belong on HBM vs. LPDDR/CXL; it remains a case-by-case design decision.

Bottom line
The real question AI has posed to the memory industry isn't "what's the new memory type" — it's how to tier existing memory to balance capacity, power, and latency. The winner of the next round won't just be whoever holds HBM capacity, but whoever finishes designing the tier beneath it first.
