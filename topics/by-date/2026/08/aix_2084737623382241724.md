#ICYMI: Today, @MarvellTech unveiled the Bravera SC6 PCIe 6.0 SSD controller at the #FMS2026, targeting next-generation enterprise and hyperscale NVMe SSDs. It delivers 2× the performance of the Bravera SC5, uses a NAND-agnostic design that provides multi-supplier flexibility, and is expected to begin sampling in Q4 2026.

The controller addresses emerging AI inference bottlenecks by supporting the offloading of less-frequently accessed KV-cache data from HBM and DRAM to SSDs, helping ease pressure on costly high-bandwidth memory. This is enabled by PCIe 6.0, which doubles the signaling rate of PCIe 5.0 to 64 GT/s per lane and provides up to 256 GB/s of aggregate bidirectional raw bandwidth over a x16 connection, using PAM4 signaling, low-latency forward error correction (FEC), and Flit-based encoding. The higher bandwidth substantially increases host-to-storage throughput, although SSDs remain significantly slower than HBM and DRAM.

Workloads that can benefit include long-context and agentic LLM inference, retrieval-augmented generation (RAG), vector databases, AI/ML training, model checkpointing, high-performance computing (HPC), real-time analytics, and large-scale enterprise data processing—particularly high-volume workloads in which storage bandwidth or I/O can become a bottleneck.

SC6 fits into Marvell’s broader AI infrastructure strategy alongside Structera CXL, which addresses memory expansion and pooling, and Photonic Fabric, which enables high-bandwidth optical data movement. Together, these technologies reflect the industry’s shift toward increasingly integrated AI memory and storage hierarchies spanning compute, HBM, DRAM, CXL-attached memory and NVMe storage to manage the growing demands of AI models, datasets and KV caches.

Visitors can visit Marvell’s booth #805 at FMS 2026 to learn more about the Bravera SC6 and the company’s latest AI memory and storage technologies. 📰👀 $MRVL
