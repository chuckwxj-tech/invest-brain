## 原文

「推論データの置き場所」特集③

CXL本命4社。

$ALAB
$MRVL
$MU
$PENG

ただし、この4社は同じCXL関連でも、狙っている取り分が全然違う。

一言で表すと、

$MU
→ メモリ容量を売る

$ALAB
→ メモリをつなぐ

$MRVL
→ メモリを広げ、束ね、演算も近づける

$PENG
→ KV Cache Serverとして完成品化する

【 $MU｜CXL Memory】

DRAMを搭載したCXL Memory Moduleを供給。

CXL普及によってサーバー1台当たりのDRAM搭載量が増えれば、最終的に「Memory Bits」を取れる。

ただし、MU全体ではHBMや通常のDRAM、NANDの影響が大きい。

CXL本命というより、

「推論のMemory Wallで、必要なメモリ容量そのものが増える」

ことへの本命候補。

【 $ALAB｜CXL Controller】

Leo CXL Smart Memory Controllerで、CPU／GPUと拡張メモリを接続する。

AzureでのCXL Memory Expansionや、PENGのKV Cache ServerにもLeoが採用されている。

CXLが普及すれば、メモリモジュールとホストの間に必要となる「接続の関所」を狙える。

CXL単体の売上規模はまだ見極めが必要だが、成功した場合の会社業績へのレバレッジは大きそう。

【 $MRVL｜CXL Fabric】

Structeraシリーズは、

X → Memory Expansion
S → Memory Pooling / CXL Switch
A → Near-Memory Acceleration

まで展開。

単なるメモリ拡張ではなく、ラック内でメモリを共有し、データの近くで処理するところまで狙っている。

4社の中ではCXL製品の守備範囲が最も広い。

一方、MRVL全体ではCustom ASIC、光、Networkなども大きいため、CXLの成功が業績に見えにくい可能性もある。

【 $PENG｜KV Cache System】

MemoryAIは、GPUからKV Cacheをオフロードする最大11TBのCXL Memory Server。

部品ではなく、

「推論Memory Wallを解消する完成品」

として売るのが特徴。

今回のテーマへの直結度は最も高い。

ただし、本当に見るべきなのは製品発表ではなく、

・顧客採用
・出荷台数
・リピート受注
・売上と利益率

まで伸びるかどうか。

現時点の仮説を整理すると、

推論への直結度
→ $PENG

CXL製品の広さ
→ $MRVL

CXL普及時の業績レバレッジ
→ $ALAB

メモリ搭載量増加の恩恵
→ $MU

つまり、この4社から1社だけが勝つとは限らない。

KV Cache Serverが普及する
↓
CXL Controller / Switch需要が増える
→ $ALAB $MRVL
↓
搭載されるDRAM容量が増える
→ $MU
↓
システムとして顧客に届ける
→ $PENG

という形で、同じ市場を別の階層から取る可能性がある。

重要なのは、

「CXL製品を持っているか？」

ではなく、

「推論Memory Wallの解消で、誰の売上と利益が最も増えるのか？」

次回は、コントローラー／スイッチ側の本命候補、

$ALAB vs $MRVL

を比較します🔍
